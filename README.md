# Horagema — переводы игр

Статический сайт-каталог игровых переводов и нейропереводов для GitHub Pages.

## Страницы

- `index.html` — главная.
- `translations.html` — список переводов игр.
- `neurotranslations.html` — нейропереводы.
- `projects/` — отдельные страницы проектов.

Сейчас в разделе переводов: Danganronpa 2: Прощай, Академия Отчаяния, Zero Escape: Virtue's Last Reward и Kamaitachi no Yoru: Rinne Saisei. Обложки и логотипы находятся в `assets/`.

## Как добавить перевод

1. Создайте страницу в `projects/`, используя существующую страницу проекта как шаблон.
2. Добавьте карточку и обновите счётчик в `translations.html`.
3. Для нейроперевода добавьте страницу и карточку в `neurotranslations.html`.

## Публикация

В настройках GitHub-репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
